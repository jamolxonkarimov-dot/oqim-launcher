# Oqim Launcher

Minimal Android launcher: vertical app list, alphabet scroller, favorites, search.

## Install
Every push to `main` builds an APK via GitHub Actions. Open the repo's **Releases** page on the phone, download `oqim-launcher.apk`, install it, then pick Oqim as the default home app.

The APK is signed with `app/oqim.keystore` (public password, personal use only) so new builds update the old install.
